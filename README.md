# MyFtp - 项目文件实时同步工具

一个类 FTP 的桌面工具，支持项目文件实时监控、自动上传、文件浏览和同步日志。

## 功能

- **服务器管理**：配置多个 FTP 服务器，支持测试连接
- **项目监控**：指定本地项目目录，文件修改后自动上传到 FTP 服务器
- **全量同步**：一键将整个项目目录同步到远程
- **文件浏览**：浏览远程 FTP 文件，支持上传/下载/删除/新建目录
- **同步日志**：记录每次同步操作，可按项目筛选

## 安装

```bash
pip install -r requirements.txt
```

> 仅需安装 `watchdog` 一个第三方依赖，其余使用 Python 标准库。

## 运行

```bash
python main.py
```

## 使用流程

### 1. 添加服务器
打开「服务器管理」标签页，填写 FTP 服务器信息（名称、主机、端口、用户名、密码、远程路径），点击「添加」。可点击「测试连接」验证。

### 2. 添加项目
打开「项目监控」标签页，填写项目名称，选择本地目录和 FTP 服务器，设置远程路径，点击「添加项目」。

### 3. 启动监控
在项目列表中选中项目，点击「启动监控」。此后该目录下的任何文件修改、新建都会自动上传到 FTP 对应路径。

### 4. 全量同步
选中项目后点击「全量同步」，会将本地所有文件一次性上传到远程（排除规则生效）。

### 5. 文件浏览
打开「文件浏览」标签页，选择服务器并连接，可以浏览远程目录、上传/下载文件、创建和删除目录。

### 6. 查看日志
「同步日志」标签页展示所有同步记录，可按项目筛选。

## 排除规则

在「项目监控」标签页可配置排除规则，用英文逗号分隔。支持：
- 目录名：`.git`, `__pycache__`, `node_modules`
- 通配符：`*.pyc`, `*.tmp`, `*.log`

## 项目结构

```
MyFtp/
├── main.py                  # 主程序入口
├── requirements.txt         # 依赖
├── README.md                # 说明文档
├── core/
│   ├── __init__.py
│   ├── config_manager.py    # 配置管理
│   ├── ftp_client.py        # FTP客户端
│   └── file_monitor.py      # 文件监控
└── gui/
    ├── __init__.py
    └── app.py               # GUI界面
```

## 配置文件位置

配置和日志保存在用户主目录下的 `~/.myftp/` 目录：
- `config.json` - 服务器和项目配置
- `sync_log.json` - 同步日志

## 环境要求

- Python 3.8+
- Windows / macOS / Linux
